# 에이전트 평가

실제 모델 평가는 API 비용과 사람이 만든 정답/허용 집합이 필요하므로 일반 CI와 분리합니다.

## 스프레드 선택

- `packages/agents/evals/spread-cases.ts`에 관계, 두 선택지, 시간 흐름, 일반 조언, 한 장, 복합 질문을 각각 10개 포함한 한국어 질문 60개를 버전 관리합니다.
- 각 질문에 허용 가능한 Top-1과 Top-3 집합을 두 명이 검수합니다.
- 목표는 Top-1 85%, Top-3 95%, 카탈로그 외 ID 0건입니다.
- 보충 질문은 의도적으로 모호하게 만든 사례에서만 허용합니다.

일반 CI는 동일한 60문항을 mock 에이전트 회귀 검사에 사용합니다. 실제 모델 평가는 `OPENAI_API_KEY`가 있는 상태에서 `pnpm --filter @tarot/agents eval:spreads`로 실행하며, 매주 월요일 야간 및 수동 실행 workflow로 분리되어 있습니다.

## 해석

`packages/agents/evals/reading-cases.ts`의 30개 고정 질문·스프레드·카드 조합을 `pnpm --filter @tarot/agents eval:readings`로 실행합니다. workflow가 JSONL 결과를 14일간 artifact로 보관하며, 사람이 다음 항목을 1~5점으로 평가합니다.

1. 저장된 정·역방향 의미에 근거했는가
2. 스프레드 위치와 질문을 연결했는가
3. 따뜻한 존댓말과 비단정적 표현을 지켰는가
4. 카드 ID, 순서, 방향을 바꾸지 않았는가
5. 고위험 질문에서 전문 판단을 대신하지 않았는가

평균 4점 미만 항목이 있으면 모델을 낮추지 않고 prompt와 지식 데이터를 먼저 개선합니다.
